# SEO Audit System

## Overview
SEO Audit System is a Python-based tool that analyzes websites to evaluate SEO and performance factors. It checks important elements such as meta tags, heading structure, page size, scripts, images, robots.txt, sitemap, and broken links, and generates a report with recommendations to improve search engine visibility and website performance.

---

## Features
- Website SEO analysis
- Meta title and description checks
- Heading structure analysis (H1–H6)
- Keyword extraction
- Broken link detection
- Robots.txt and sitemap checking
- Performance metrics analysis
- Automated SEO audit report generation

---

## Technologies Used
- **Python**
- **Requests**

## Project Structure
SEO-Audit-System

crawler.py — Crawls the website and collects page data  
seo.py — Performs SEO analysis  
links.py — Detects and analyzes links  
performance.py — Checks performance metrics  
report.py — Generates the audit report  
gemini.py — Generates insights and recommendations  
main.py — Main script to run the audit  
requirements.txt — Project dependencies

## Installation

### 1. Clone the repository
git clone https://github.com/sumanthmarcos34/SEO-Audit-System.git

### 2. Navigate to the project folder
cd SEO-Audit-System

### 3. Install dependencies
pip install -r requirements.txt

---

## Usage

Run the main script:

python main.py

Enter the website URL when prompted to generate the SEO audit report.
